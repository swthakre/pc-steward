# Changelog

All notable changes are recorded here. Version 0.1.0 is a development version, not a production release.

## [Unreleased]

### Added

- Aurora Light native WPF application shell and volume overview.
- Bounded read-only disk scanner with cancellation, coverage reporting, nested folders, treemap and file-type totals.
- Local JSON/CSV export and scan CLI.
- Aged TEMP metadata preview without deletion.
- Read-only app, startup, process, service, task and basic hardware inventories; Defender status query.
- Core fixture tests and native WPF render/navigation tests.
- GPL-3.0-or-later licensing, development documentation and Windows CI.

### Known limitations

- Not a completed milestone A or premium-feature parity release.
- 100,000-entry scan cap; logical bytes only; indexed/allocated accounting pending.
- Cleanup, recovery, vulnerability matching, malware scans, automation and privileged operations are not implemented.
- Portable development builds are unsigned; production release qualification is pending.
